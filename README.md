# The Mark UChicago — Website

The Mark UChicago's marketing site, redesigned. Built with [Next.js](https://nextjs.org) (App Router) and [Tailwind CSS](https://tailwindcss.com), deployed on [Cloudflare Pages](https://pages.cloudflare.com).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Structure

- `src/app/` — pages: Home, About, Services, Portfolio, Contact
- `src/components/` — shared Nav and Footer
- `public/brand/` — logo lockups, icon marks, and background texture

Brand color: `#53b9ed`.
